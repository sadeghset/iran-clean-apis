# Iran API Finder

A simple static website for discovering APIs suited to Iranian internet conditions.

## Run locally

Open `index.html` directly in a browser or serve it with a tiny local server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Features

- Mobile-friendly dashboard layout
- Search by API name or keyword
- Filters for low-bandwidth, CDN, auth, maps, and payments
- Lightweight API cards with latency and stability indicators
- Good starting point for a product or portfolio page

## Notes

This is a demo dataset for UI/UX exploration. For production, replace the sample data with your real API catalog and metrics.

## Repository

This project is ready to be adapted into a larger app if you want to add:

- real API registry data
